name: test-first
description: Use for any coding task that fixes a bug or implements a feature in a repository with tests. Read the relevant tests before changing code, then run them before finishing.
---

# Test first

1. Find the tests that cover the change. If the task names test files, read them first, even if they do not exist yet.
2. Write down, in one line each, the behaviours the tests will check.
3. Make the smallest change that satisfies those behaviours. Do not refactor unrelated code.
4. Run the project's test command. If anything fails, fix the code, not the tests.
5. Stop as soon as the tests pass.
