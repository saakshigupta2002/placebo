Each task is a real change from the repository's history. The agent runs it twice in identical sealed workspaces exported without git history: once as is (control) and once with the intervention (treatment). Hidden tests from the original change grade both attempts. Effects are estimated per task and averaged across tasks; p-values come from an exact paired sign-flip permutation test across tasks.
