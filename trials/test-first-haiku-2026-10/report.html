How this was measured

Each task is a real change from the repository's history (or a hand-written task with its own check). For every task the agent runs in fresh workspaces exported from the starting commit with no git history, so it cannot find the answer in future commits. Control runs the agent as is. Treatment runs the same agent with the skill under test. Nothing else differs.

After each run, hidden tests from the original change are restored over whatever the agent left, then the task's check command decides pass or fail. Tokens and cost come from the agent's own usage report.

Effects are estimated per task and then averaged across tasks, so repeats sharpen each task's estimate without counting as extra evidence. Pass rate is a difference in percentage points. Tokens, cost and time are geometric-mean ratios. P-values come from an exact paired sign-flip permutation test across tasks. The 95% intervals come from inverting that same test, so an interval excludes zero exactly when p is below 0.05.
