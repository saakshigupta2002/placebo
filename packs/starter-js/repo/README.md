# kit

Small, dependency-free JavaScript utilities. ESM only, Node 18+.

| Module | What it does |
|---|---|
| `duration.mjs` | Parse human durations like `1h30m` into milliseconds |
| `slugify.mjs` | Turn titles into URL slugs |
| `lru.mjs` | A least-recently-used cache |
| `semver.mjs` | Compare semantic version strings |
| `csv.mjs` | Parse CSV text |
| `merge.mjs` | Deep-merge plain objects |
| `roman.mjs` | Roman numeral conversion |
| `wrap.mjs` | Word-wrap text to a width |
| `intervals.mjs` | Merge overlapping numeric intervals |
| `toposort.mjs` | Order tasks by their dependencies |
| `query.mjs` | Parse and build URL query strings |
| `money.mjs` | Format integer cents as money |

Run the tests with `npm test`.
